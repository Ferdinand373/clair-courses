# Clair Courses V11.7

Évolution ciblée de la V11.6 pour utiliser Clair Courses comme une liste de courses autonome, sans recette obligatoire.

- action rapide « Ajouter un article » conservée en haut de la liste ;
- un seul champ libre accepte directement `2 échines de porc`, `1 kg de pommes de terre` ou `6 œufs` ;
- le texte saisi reste la référence affichée et enregistrée ;
- classement automatique avec possibilité de corriger le rayon ;
- action « Ajouter plusieurs articles » avec une ligne distincte par retour à la ligne ;
- lignes vides ignorées et ordre de saisie conservé dans chaque rayon ;
- produits inconnus acceptés dans « Divers » ;
- regroupement uniquement lorsque le produit et les quantités sont compatibles sans ambiguïté ;
- pâtes, pâte et pâté restent distincts, tout comme les autres variantes culinaires ;
- modification, suppression, cochage, persistance et « Nouvelle liste » fonctionnent comme pour les articles importés ;
- « Mes produits » n’est jamais modifié, sauf si l’utilisateur coche volontairement « Garder aussi dans Mes produits » ;
- imports Clair Repas V4.3 et correctifs V11.5/V11.6 préservés ;
- cache hors ligne identifié comme Clair Courses V11.7.

L’architecture, l’apparence générale, les rayons et les données existantes restent inchangés.
